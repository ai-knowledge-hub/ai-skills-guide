# Test Prompts

1. Review a paid search agent that can increase campaign budgets, pause keywords, and generate weekly performance summaries.
2. Assess the risk of a lifecycle CRM agent that reads customer purchase history and can schedule email sends.
3. What approval gates should we add before allowing an agent to publish product copy to the CMS?
4. Classify risks for a BI agent that queries customer-level conversion data and posts summaries to Slack.
5. Review this agent setup: it uses a human OAuth token, can export audience lists, and has only prompt instructions for compliance.
