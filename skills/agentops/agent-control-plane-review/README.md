# Agent Control Plane Review

A review skill for turning agent architecture discussions into a practical deployment-readiness checklist.

Use it before a marketing, commerce, analytics, or engineering agent is allowed to call production tools. It focuses on six control areas:

- agent identity
- gateway and tool boundary
- policy enforcement
- approval gates
- runtime inspection
- audit evidence

This skill is analysis-only. It should recommend controls, not grant permissions or execute operational actions.
