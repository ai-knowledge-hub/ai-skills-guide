# Shared Contracts

This directory contains normative, versioned contracts shared by catalog
producers and consumers. Explanatory documentation may link to these files but
must not redefine their terms.

- [Catalogue compatibility information v1](catalogue-compatibility-v1.md)
- [Withdrawn operational compatibility design v2](operational-readiness-v2.md) — historical reference
- [Operational readiness and promotion contract v1](operational-readiness-v1.md)
- [Manifest execution, artifact, authentication, and verification contract v2](manifest-contract-v2.md)

Contract filenames include their major version. Breaking semantic changes
require a new file; compatible clarifications update the contract version in
the existing file.
